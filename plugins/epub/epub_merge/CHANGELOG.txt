== 2.7.0 ==
Changing the book to keep in the merge dialog now moves its lock at once: the kept book is ticked and marked Kept, and the book you kept before can be unticked. The dialog counts only the books to merge, and its button says how many. A book titled like the story whose first chapter has no number is now taken as part 1, so it is the book kept and the merged title's range starts at 1. A merged title's range ends at the last chapter of a range such as 441-450. The message after a merge names the kept book as a link to it. Needs ebookerr 2.24.18 or later.

== 2.6.2 ==
A merge that fails on a book's internal structure now tells you to re-pull the book or run Normalize styling on it; EPUB Validate is gone. Needs ebookerr 2.24.17 or later.

== 2.6.1 ==
A merge that is refused is now counted as skipped for every selected book, with the reason, and a merge that fails as failed for each of them, instead of done.

== 2.6.0 ==
Updated for ebookerr's plugin interface 3.1; it works as before. Needs ebookerr 2.24.1 or later.

== 2.5.0 ==
The help of "Rewrite the book title with the chapter range" now uses an invented example. Updated for ebookerr's plugin interface 3.0. Needs ebookerr 2.24 or later.

== 2.4.0 ==
A merged book keeps the web address each chapter page declares as its own, including a canonical address, instead of being given the book's address. ebookerr now records the merged chapters' real web addresses for the merged book.

== 2.3.0 ==
Declares that it accepts merge suggestions in the new manifest format. Needs ebookerr 2.21 or later.

== 2.2.0 ==
Reading positions are no longer rearranged by the merge itself: ebookerr now carries every merged book's reading history into the merged book, and your current position is the one you read most recently.

== 2.1.0 ==
Moved out of the ebookerr core.
