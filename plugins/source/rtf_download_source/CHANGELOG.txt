== 1.5.1 ==
Updated to striprtf 0.0.35.

== 1.5.0 ==
A book pulled from a catalog's listing still takes its title, author and author link from the listing when the listing has them from the site, rather than from the downloaded file. Needs ebookerr 2.24.21 or later.

== 1.4.0 ==
Keeps every paragraph of an RTF file instead of running each chapter together, takes the title and author from the file's own document information, and puts the text above the first chapter on the title page instead of making it a chapter. An RTF it cannot convert says why in one sentence. Needs ebookerr 2.24.9 or later.

== 1.3.1 ==
Uses striprtf 0.0.33, the version this release was tested with; newer striprtf releases arrive as updates of this plugin a few days after they are published.

== 1.3.0 ==
Its card now shows that it uses the sign-ins stored in Settings → Credentials for the sites it downloads from. Updated for ebookerr's plugin interface 3.0. Needs ebookerr 2.24 or later.

== 1.2.0 ==
Also converts RTF files you add from your computer: Add books turns each into an EPUB and reviews it like any other. Needs ebookerr 2.22 or later.

== 1.1.0 ==
Moved out of the ebookerr core.
