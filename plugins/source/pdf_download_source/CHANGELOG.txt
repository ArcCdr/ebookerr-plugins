== 1.5.1 ==
Updated to pymupdf 2.0.

== 1.5.0 ==
A book pulled from a catalog's listing still takes its title, author and author link from the listing when the listing has them from the site, rather than from the downloaded file. Needs ebookerr 2.24.21 or later.

== 1.4.0 ==
A PDF it cannot convert now says why in one sentence — damaged, password-protected, or without text — instead of a technical error. A chapter from a PDF's outline no longer repeats its heading as its first paragraph.

== 1.3.1 ==
Uses pymupdf 1.28.2, the version this release was tested with; newer pymupdf releases arrive as updates of this plugin a few days after they are published.

== 1.3.0 ==
Its card now shows that it uses the sign-ins stored in Settings → Credentials for the sites it downloads from. Its licence is now declared as AGPL-3.0-or-later, the licence of the PDF library it uses. Updated for ebookerr's plugin interface 3.0. Needs ebookerr 2.24 or later.

== 1.2.0 ==
Also converts PDF files you add from your computer: Add books turns each into an EPUB and reviews it like any other. Needs ebookerr 2.22 or later.

== 1.1.0 ==
Moved out of the ebookerr core.
