== 1.4.0 ==
A book pulled from a catalog's listing still takes its title, author and author link from the listing when the listing has them from the site, rather than from the downloaded file. Needs ebookerr 2.24.21 or later.

== 1.3.0 ==
An EPUB pulled from a link now keeps every author, its publisher (unless it only names the site), its identifiers, series and tags, and its language, exactly as the same file uploaded would; before, only the first author was kept. Needs ebookerr 2.24.10 or later.

== 1.2.1 ==
Its icon is now a book with a globe, so it no longer looks like the Install button.

== 1.2.0 ==
Its card now shows that it uses the sign-ins stored in Settings → Credentials for the sites it downloads from. Updated for ebookerr's plugin interface 3.0. Needs ebookerr 2.24 or later.

Moved out of the ebookerr core.
