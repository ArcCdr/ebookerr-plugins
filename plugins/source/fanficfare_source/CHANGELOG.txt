== 2.2.0 ==
Chapters a site removes are kept by ebookerr itself, with their own titles. Merged books update again: FanFicFare now recognises the chapters of a book you merged. A book with chapters ebookerr kept is checked by chapter address, so it is pulled only when the site has something new. A story that no longer exists on its site is reported as gone, so ebookerr can stop checking it. FanFicFare asks for your stored sign-in only on sites where it can sign in. Needs ebookerr 2.24.17 or later.

== 2.1.1 ==
A story's description keeps its paragraphs instead of running them together.

== 2.1.0 ==
Advanced FanFicFare options are checked when you save them: a line FanFicFare cannot read is refused with its line number, and a username, password or cookie line is refused with a link to Settings → Credentials, where sign-ins belong. The switches and fields on this plugin's card now win over the same options in Advanced FanFicFare options, for every site; saving such a line shows a warning naming the card's control. Tags to keep now decides a book's tags on every site: a pull keeps the genres, characters, ships and freeform tags it names, not only Literotica's story tags, each tag once; an untouched list moves to the new default, genre, characters, ships, freeformtags, eroticatags. Books gain their tags on their next update; the plugin's row reads "Tags kept: …". A refused login now names the site and says whether its stored sign-in was refused or none is stored, and a failed download is one plain sentence. Needs ebookerr 2.24.14 or later.

== 2.0.2 ==
Uses FanFicFare 4.62.0, the version this release was tested with; newer FanFicFare releases arrive as updates of this plugin a few days after they are published.

== 2.0.1 ==
Its icon is now a scroll and quill, so it no longer looks like the Stories page and the reader.

== 2.0.0 ==
Set FanFicFare up in Settings → Plugins: Confirm adult content, Include images, Keep the summary's formatting, Use the first image as the cover, Tags to keep, and Advanced FanFicFare options for anything else, in FanFicFare's own format. Sign-ins come from Settings → Credentials — the username and password stored for the story's site — and update checks use them too. personal.ini is no longer used and is removed the first time the plugin runs: before updating, copy anything you changed in it into Advanced FanFicFare options. ebookerr now chooses every file name and folder. Its card shows that it uses your site sign-ins. Updated for ebookerr's plugin interface 3.0. Needs ebookerr 2.24 or later.

== 1.4.0 ==
Updating a story now downloads only its new chapters instead of the whole story, checks the newest chapter for edits, and keeps chapters the site has removed. Every update is checked before it is saved: if the result does not add up, the pull fails with the numbers and your book stays as it was. A book whose file FanFicFare cannot update, such as a merged book, now fails with a clear message instead of silently missing new chapters. Failures say what went wrong (story not found, login refused, site unreachable), and the progress bar follows the chapters. Needs FanFicFare 4.62 or later.

== 1.3.0 ==
A series named with its number, like "Harbour Stories [2]", is now stored as the series "Harbour Stories" with series number 2. Tags are stored in ebookerr's tags field. Needs ebookerr 2.22 or later.

== 1.2.0 ==
Declares itself the Source of last resort in the new manifest format. Needs ebookerr 2.21 or later.
